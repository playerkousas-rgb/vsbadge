## 短版（群組／電郵）

**事由：進度系統「主系統免登入」功能發現保安漏洞，已完成修補**

各位執委：

我哋嘅「深資童軍進度系統」（vsbadge）同執委管理平台（82venture）係連埋嘅 ——
喺 82venture 撳「深資童軍進度追蹤」張卡，會自動帶入身份、唔使再登入。

早前發現呢個「免登入」機制有個保安漏洞：
**任何人只要砌一條網址，就可以用執行委員會／甚至最高管理員嘅身份進入任何旅團嘅進度系統**，
唔使密碼、唔使嚟自 82venture。即係可以睇到全團成員嘅進度紀錄，並可進行勾選。

**已經修補好，並已上線。** 而家系統會先向伺服器查證三件事先至放行：
1. 呢個旅團有冇登記、准唔准經主系統進入
2. 係咪真係由 82venture 嘅網站帶人入嚟（核實來源網址）
3. 帶入嚟嘅角色係咪喺旅團預先批准嘅名單入面

**執委會需要做嘅嘢：**
- **唔使做任何嘢**，亦**唔使**重新部署任何 Google Sheet／Apps Script
- 系統管理員已經喺 Vercel 設好主系統網址（`PORTAL_DEFAULT_ORIGIN`）同批准角色名單
- 成員用緊嘅登入方式（開 vsbadge → 揀旅團 → 輸入 YMIS／電郵 + 密碼）**完全冇變**

**日常使用上嘅影響：**
- 一定要**由 82venture 撳卡片／連結進入**。如果有人把條網址 copy 出嚟自己貼去瀏覽器開，
  系統會拒絕並顯示原因（呢個係刻意嘅保護）
- 如果唔小心入唔到，畫面會明確講「邊一關過唔到」同錯誤代碼，照住提示做就得

**風險評估：** 漏洞屬「未授權進入」類，只影響經 82venture 免登入嘅入口；
以帳號密碼登入嘅軌道完全冇受影響。我哋冇證據顯示有未授權嘅實際查閱，
但保守起見已按最高等級處理，並喺修補後收緊晒所有入口。

## 中版（如果執委會想要多少少技術細節）

**漏洞內容（技術）**
`/api` 前端舊版只檢查網址參數 `from=portal` + `ymis` + `role`，完全冇驗證來源。
`?u=0082&from=portal&role=super_admin&ymis=x` 呢條網址會令系統直接建立一個
`can_tick: true`、`allowed_badges: '*'` 嘅超管 session，並顯示「用戶管理」「審批中心」。

**修補方式（技術）**
- 新增同源驗證 endpoint `/api/portal`：免登入前一定要問伺服器
- 伺服器四關把關：旅團已登記 → 已開放主系統接入（`PORTAL_DEFAULT_ORIGIN`）
  → 來源網址（瀏覽器 `Referer` 或主系統送出嘅 `src`）對得上 → 角色喺白名單內
- 唔加 CORS header，只畀同源前端用；所有回應 `no-store`；log 唔記任何敏感資料
- 拒絕時前端明確顯示原因（例如「只接受由 82venture 進入」），**唔會**再無聲跌落登入頁
- `ymis` 改為可省略：由主系統自己派身份，新旅團接入唔使再設定

**冇郁過嘅嘢（重點）**
- `apps-script/Code.gs` **一個字都冇改** → **旅團唔使重新部署 Apps Script**
- `/api/proxy` 嘅安全設定（action 白名單、伺服器端解析 GAS 網址、唔 log 密碼／token）全部照舊
- Google Sheet 資料結構、現有帳號、密碼、token 冚唪唦冇變
- 以帳號密碼登入嘅軌道（軌道 A）完全冇影響

**回歸測試**：153 項自動化測試全部通過（其中 30 項係今次新增嘅 Portal 驗證，
包括「砌 URL 攞超管」嘅漏洞重現測試，確認而家會被拒絕）。

## 常見問題（追問點答）

**Q：要唔要重新部署我哋嘅 Google Sheet / Apps Script？**
A：唔使。今次改動純粹係前端程式（一個 HTML）加 Vercel 伺服器端嘅驗證程式，
Apps Script 完全冇改，Sheet 資料亦冇郁過。

**Q：而家 0082 用緊，會唔會整壞佢？**
A：唔會。成員／領袖用帳號密碼登入嗰條路完全冇改。唯一會變嘅係「由 82venture
免登入進入」—— 修補之後一定要由 82venture 嘅卡片／連結進入，並要管理員設好
主系統網址。我哋會**先設好網址先至部署**，中間唔會有空窗。

**Q：係咪即係話之前有外人入過？**
A：冇證據顯示有。發現到之後我哋即時修補同收緊，冇等到下一次版本。
如果執委會想，我哋可以加做一次存取紀錄檢查。

**Q：第時轉主系統網址點算？**
A：管理員改一條環境變數（`PORTAL_DEFAULT_ORIGIN`）再重新部署就得，
唔使改程式、唔使逐個旅團改，所有旅團一次過生效。

**Q：新旅團接入要搞幾多嘢？**
A：幾乎零。旅團照常登記旅團編號同 Google Sheet 後端（URL + API Key），
就自動可以經 82venture 進入，唔使再為「免登入」加任何設定。

**Q：管理員可以點樣收緊／放寬？**
A：兩條環境變數控制晒：`PORTAL_DEFAULT_ORIGIN`（邊個網站可以帶人入嚟）、
`PORTAL_DEFAULT_ROLES`（准帶邊啲角色入嚟，現時係執委／支部領袖／團長）。
個別旅團要例外（例如唔想開放）都可以逐個設定。
