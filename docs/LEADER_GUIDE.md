# 👨‍💼 領袖使用教學 (Branch Leader / Group Leader / Admin / 超管)

> 你擁有全部權限，負責審批、授權、批量操作

## 核心功能

### 1. 我的進度 - 選成員看所有紀錄
- 頂部「檢視成員」下拉選任何人，查看其完整進度（包括其他獎章）
- 直接勾選 + 輸入日期（剔即填今日，可手改日期）
- 級聯自動完成：勾上層自動勾所有下層
- 離線暫存 → 底部 SaveBar 顯示數量 → 按確認才批量寫入雲端，有進度提示

### 2. 全團總覽 - 一眼睇 + 批量剔
- **卡片總覽**：每人完成度% + 四個獎章百分比，一眼睇邊個完成會員章（顯示會員章✓標籤）
- **表格矩陣**：按段章篩選，最多30欄防卡死，點✓可單獨切換
- **🚀考驗營批量完成**：例如剛去完考驗營
  - 選日期
  - 左選有去的成員（支援搜尋過濾，全選/取消全選）
  - 右選本次考驗的項目（支援全選）
  - 一鍵標記 → 暫存 → 確認寫入，唔使逐個跳轉
- **按成員/按項目統計**：子切換按鈕，一個分頁內完成（手機省闊度）

### 3. 待批 - 成員申請
- 成員「申請完成」後在此顯示，含日期、證據
- 可單個批准/拒絕，或批量選中批准
- 批准後自動加入待寫入清單

### 4. 表格列印 - 官方格式
- 自動填入姓名、YMIS、旅團、段章完成日期、其他獎章
- PT/19 深資童軍獎章、PT/20 榮譽章（龍章）官方格式，含個人摘要、完成項目、提名/推薦/批核簽署欄
- 可編輯後列印，雙面列印符合總會要求

### 4b. 📅 活動履歷 - 服務／活動／訓練班紀錄（v8.1）
- 記錄成員參加的各項活動：**🤝 服務紀錄**（名稱、崗位、時數，自動統計總時數）、**🏕️ 活動紀錄**（露營、比賽、參觀等）、**🎓 訓練班紀錄**（班名、身份、時數、證書編號）
- 「檢視成員」可切換任何成員；成員登入則唯讀看自己
- **➕ 新增紀錄**：選類型 → 成員 → 日期 → 名稱 →（崗位／時數／證書編號按類型顯示）→ 儲存
- **📥 批量補登**：新增時勾「批量：同一活動套用到多個成員」，例如全團露營一次過幫 20 人建立（單次最多 200 筆）
- ✏️ 編輯／🗑️ 刪除：紀錄右側按鈕（刪除會先確認，且寫入操作紀錄可追查）
- 權限：與進度寫入相同——需角色含勾選權且「授權勾選」開啟的領袖；成員唯讀
- **📅 履歷申報審批**（v8.4）：成員可在「活動履歷」按「📝 申報紀錄」自行申報，或對已批紀錄提交「修改申報」。你在「審批中心」→「📅 履歷申報」逐項批准／拒絕：
  - 批准「新增申報」→ 寫入活動履歷（記錄人顯示「XX（自行申報）」）
  - 批准「修改申報」→ 以同一紀錄更新（審批卡會顯示原紀錄內容方便對照）
  - 只有履歷有「批後可再申報修改→重批」機制；進度待批及其他獎章批准後只有領袖可改
- ⚠️ 如顯示「後端尚未升級 v8.1」：請按 [DEPLOY_GUIDE](../DEPLOY_GUIDE_FOR_TROOPS.md)「v8.1 升級」更新 Code.gs + 執行 initializeSheets + 新版本部署，其他功能不受影響；履歷申報需再按「v8.4 升級」補建「待批履歷」工作表

### 5. 用戶管理 - 全前端行政、角色及細緻權限
- 單一開戶：填寫 YMIS、姓名、Email、角色及臨時密碼
- **📥 批量開戶（推薦 YMIS）**：從青少年成員資訊系統匯出自訂報表 PDF（欄位次序：童軍成員編號 → 中文姓名 → 電郵地址）→ 瀏覽器內解密／預覽／修改 → 確認開戶。PDF 不會上傳伺服器。詳見 [YMIS_EXPORT.md](YMIS_EXPORT.md)
- **CSV／JSON 備用**：下載 CSV → 上傳預覽 → 前端驗證 → 批量寫入；空白密碼可自動產生
- 編輯用戶資料、重設臨時密碼、停用／重新啟用帳戶、查看操作紀錄
- 新帳戶及重設密碼後，首次登入會強制改密碼
- 將成員改為執委：選單改角色 + 授權勾選
- **⚙️權限按鈕**：
  - 領袖默認全部(*)
  - 成員默認無
  - 執委默認 L1會員章 + L3活動段章 + OTHER部分
  - 可按個別成員勾選可考核什麼：會員章、活動段章（細項不用）、其他獎章逐個勾
  - 高層級可設定低層級可勾選範圍，除非團長/管理員更改
- 授權/收回勾選權限

### 6. 系統設定 - 私隱開關
- **允許成員互相查看進度**：預設關（只看自己，重私隱），團長可開啟（互相鼓勵，執委可按進度策劃活動）
- 在用戶管理頁 → 系統設定 → 開關
- 成員是否可看其他人進度由此控制

### 7. 審批申請（新帳號）
- **團長／支部領袖**登入 → **✅ 審批中心** → **👤 用戶審批**，即可批准／拒絕成員、執委、領袖的帳戶申請（團長預設已可審批，毋須另行設定）。
- 申請會顯示申請人要求的身份（團員／執委／支部領袖）及所屬旅團（自動帶入）。
- 批准時系統**按申請身份直接開戶**；若審批者權限層級未能設定該角色（例如支部領袖批准「支部領袖」申請），會退回以團員開戶，屆時由團長在「用戶管理」調整角色。
- 批准後會顯示**一次性臨時密碼**，請安全地個別交給申請人；首次登入強制更改。
