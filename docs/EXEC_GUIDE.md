# 🎖️ 執委使用教學 (Exec Committee)

> 你由成員晉升為執委，擁有部分領袖權限，可協助考核

## 你比成員多什麼？
- 成員的所有功能
- **可勾選進度**（需領袖授權可勾選範圍）
  - 默認可考核：**會員章 + 活動段章(細項不用勾，勾段章即可) + 其他獎章逐個勾**
  - 團長/管理員可在「用戶管理」→ 按你帳號旁「⚙️權限」設定你可考核哪些段章
- **可選成員查看**：在「我的進度」頂部可選其他成員，看他所有紀錄，方便策劃活動
- **全團批量**：若被授權，可在「👥全團總覽」使用「🚀考驗營批量完成」：
  1. 選日期
  2. 左選有去的成員（可搜尋過濾）
  3. 右選本次考驗的項目
  4. 一鍵標記完成 → 暫存瀏覽器 → 底部按確認寫入雲端

- **待批**：若被授權，可批准成員的「申請完成」

## 如何幫成員勾選？
1. 我進度頁選成員
2. 找到項目，直接勾選 + 改日期（自動填今日，可手改）
3. 所有勾選先存瀏覽器，底部顯示數量，按「確認寫入雲端」才批量寫入，有「正在寫入」提示

## 策劃活動
執委可按全團進度策劃活動：例如在全團總覽一眼睇邊個未完成會員章，針對性安排戶外活動。

## 由主系統（Portal）進入 — 免登入

如果你哋旅團已接駁主系統（例如 82venture），在主系統 Dashboard 點「深資童軍進度追蹤」卡片
就會**自動帶入身份、唔使再登入**，介面右上角會見到藍色 `Portal` 標籤。

- 主系統會把你嘅角色（例如執委）一併帶過來，權限同平時登入一樣
- 唔使記 vsbadge 密碼；`ymis` 亦唔使你填，系統會自動產生 `PORTAL-<旅團>-<角色>`
- **要由主系統嘅卡片／連結進入**：v3.1 起 vsbadge 會核實來源網址，直接把條網址複製去
  瀏覽器開、或者由第啲網站連過來，會被拒絕並顯示原因（呢個係為咗防止有人自己砌
  `?role=super_admin` 攞管理員權限）

常見拒絕原因：

| 代碼 | 意思 | 點做 |
|---|---|---|
| `referer_mismatch` | 唔係由已登記嘅主系統網址進入 | 返去主系統，由卡片／連結再開一次 |
| `role_not_allowed` | 旅團未開放你呢個身份經主系統接入 | 通知團長／管理員把角色加入 `portalRoles` |
| `troop_not_portal_enabled` | 旅團未接駁主系統 | 通知管理員登記主系統網址 |
| `no_origin` | 來源網址確認唔到（例如直接用 curl 開） | 由主系統卡片開啟 |

獨立使用（軌道 A：打開 vsbadge.vercel.app → 選旅團 → 登入）完全不受影響。
