# 👤 成員使用教學 (Member)

> 你只需關心自己的進度，其他功能由領袖處理

## 登入後你會見到
- **📊 我的進度**：預設只顯示你自己的完成度
  - 綠色進度條 = 已完成比例
  - 點擊獎章展開段章，再展開項目
  - 每項右側有 ⓘ 查看考驗說明，不用翻綱要
  - **不能直接剔**：你只能按「📝 申請完成」

- **⭐ 其他獎章**：已併入「我的進度」最底虛線卡片，顯示急救章、AYP、拯溺等，你的紀錄在此

- **📝 待批**：查看你提交的申請是否已批，狀態：⏳待領袖確認 / ✅已批准

- **📅 活動履歷**（v8.1／v8.4）：查看你的 **服務紀錄**（含時數）、**活動紀錄**、**訓練班紀錄**（含證書編號）
  - **📝 申報紀錄**（v8.4，需旅團後端升級）：可自行申報新紀錄，提交後由領袖審批，**批准後才會寫入**你的履歷；批准前可自行取消
  - **✏️ 申請修改**：已批准的紀錄如需更正（例如時數、日期），按紀錄旁 ✏️ 提交修改申報，經領袖**重批**後才會更新；同一紀錄同時只可有一個待批修改
  - 領袖亦可直接替你補登；如後端未升級 v8.4，請通知領袖代為輸入

- **🖨️ 表格列印**：系統會自動根據你的進度填好 PT/19 (深資童軍獎章) 及 PT/20 (榮譽章/龍章) 所需日期，你可編輯地址、區、地域後直接列印，官方格式，記得雙面列印

- **📚 資料庫**：保護兒童 Safe from Harm 課程連結、訓練綱要、佩戴指引

- **❓ 教學**：此文件，按角色只顯示你需要的部分

## 常見操作
### 如何申請完成一個項目？
1. 在「我的進度」找到該項目
2. 按右側「📝 申請」
3. 選完成日期 + 填寫證據（例如：2026-05-01 考驗營相片3張）
4. 按提交，**先暫存瀏覽器**，領袖會在「待批」看到
5. 領袖批准後，底部會顯示已寫入，進度自動更新

### 為何我看不到其他成員？
預設為私隱，普通成員只能看自己。若旅團想互相鼓勵，團長可在「用戶管理」→「系統設定」開啟「允許成員互相查看進度」。

### 忘記密碼？
1. 在登入頁按 **「🔑 忘記密碼？」**，只需輸入 YMIS 或已登記電郵其中一項。
2. **已登記電郵**：你會收到 8 位重設碼（15 分鐘內有效，可直接貼上）。在同一個畫面輸入重設碼，再輸入新密碼（最少 4 位）兩次即完成，毋須通知任何人。
3. **未登記電郵**：系統唔會寄信畀你，請直接聯絡領袖為你重設臨時密碼；首次登入時須立即更改。為咗唔洩露邊啲帳號有登記電郵，畫面喺呢種情況都會顯示同一句提示，所以等唔到信就直接搵領袖。
4. **收唔到信？** ① 先檢查垃圾郵件匣 ② 確認輸入的是「登記咗」的電郵（或者正確的 YMIS） ③ 仍然收唔到就聯絡領袖或部署者。重新申請新碼之後舊碼會即時失效；重設成功後其他裝置的登入會立即失效，返去登入頁用新密碼登入即可。
5. 連續 5 次入錯密碼，帳號會鎖 15 分鐘（期間輸入正確密碼都唔得，而且畫面只會話「帳號或密碼錯誤」）。等 15 分鐘再試，或者叫領袖重設密碼，即時解除。

### 如何開立帳戶？
- 在登入頁按 **「🆕 申請帳戶（成員／執委／領袖）」**，選擇申請身份（團員／執委／領袖），填寫 YMIS、姓名及電郵（執委／領袖必填）。
- **毋須填寫支部／單位**：支部＝深資童軍（本系統），單位＝所選旅團，系統自動帶入。
- 提交後由團長／支部領袖在「審批中心」→「用戶審批」批准，獲發一次性臨時密碼。首次登入時系統會強制立即更改。
- 團長／管理員角色須由現任團長在「用戶管理」直接開立。
- 亦可聯絡團長／支部領袖在「用戶管理」重設臨時密碼。
